# BLCKTHRN (blckthrn.c): Lord Blackthorn's cutscenes: the party is captured (BLCKTHRN_060e), questioned about the
# virtues in his throne room (his test), and the Avatar's death scene (BLCKTHRN_0910). One overlay.
# The cutscene scripts are byte strings run by BLCKTHRN_00be: 1 pair the next move with the one after, 2 n repeat the
# next move n times, 3/4 footsteps on/off, 5 n wait n frames, 6 tile x y set a map cell, 7 redraw, 8 footsteps for the
# repeat count, 9 n hide actor n, 0 ends; a code of 0x10 or more is a move: (code & 0xfc) picks the actor, (code & 3) the direction.
# functions
BLCKTHRN_0000 BLCKTHRN_0000_Footsteps              # so many footsteps, two frames each
BLCKTHRN_002e BLCKTHRN_002e_MoveActorOf            # a script move code: the actor it moves (0x10 -> 6, 0x14 -> 7, 0x18 -> 8, 0x1c -> 0, 0x20 -> 1); the step is left in D_5876/D_5878
BLCKTHRN_00be BLCKTHRN_00be_RunScript              # runs a cutscene script (codes above)
BLCKTHRN_0278 BLCKTHRN_0278_AskVirtue              # prints question 0-3 of the scene's text (D_b21e) and the virtue's name; question 3 has no virtue
BLCKTHRN_02ea BLCKTHRN_02ea_ReadMantraAnswer       # reads "Your response?" and tells whether it contains the virtue's mantra (any case)
BLCKTHRN_03ae BLCKTHRN_03ae_SlicePartyMember       # a thunderbolt and a sound sweep, the actor at slot 1 vanishes; the second living member leaves the party (to slot 15)
BLCKTHRN_0510 BLCKTHRN_0510_KeyThenScript          # waits for a key, then runs the script D_369e
BLCKTHRN_051c BLCKTHRN_051c_ThreatenCompanion      # the first threat: scene text, the script D_36da, then the second member is to die
BLCKTHRN_054a BLCKTHRN_054a_Interrogation          # up to four rounds about the virtue: an answer with its mantra marks the shrine 0xff, costs 5 karma and ends it; a round may slice a member
#= BLCKTHRN_060e_Capture # the party is captured: the first intact shrine's virtue is the topic; guards, chains, Blackthorn's speech, the interrogation; then the party is set at the castle (10, 7)
#= BLCKTHRN_0910_Death # the death scene: darkness, "Thou hast found refuge", the old man speaks by karma, the party is resurrected and put at (10, 10) of map 0x11
