# CAST2 (cast2.c): the helpers of the spell code (select a spell, who, which direction, the
# effects of the spells that need more than a few lines), the shrines and the Codex, saving the game. One overlay.
# functions
CAST2_0306 CAST2_0306_AskDirection           # "Direction-": an arrow key; the cell beside the actor (or party) is left in D_5876/D_5878; 0 for Pass
CAST2_03c2 CAST2_03c2_HealMember             # 1 to 30 hit points, up to the maximum; 0 for the dead
CAST2_046c CAST2_046c_WisAnYlem              # (Wis An Ylem, "AWY"): the view built with the walls seen through, animated for 20 frames
CAST2_04c2 CAST2_04c2_KalXenCorp             # (Kal Xen Corp, "CKX"): gates in a daemon (0x26) charmed; the spell may fail and leave it hostile
CAST2_06ec CAST2_06ec_PrintPosition          # (In Wis, "IW"): prints the position as letters, A'B", C'D" (x and y, each as two hex digits + 'A')
CAST2_0768 CAST2_0768_InExPor                # (In Ex Por, "EIP"): turns a door tile 97 or 98 into the open door; -1 without a direction
CAST2_07bc CAST2_07bc_AnGrav                 # (An Grav, "AG"): destroys a field: the dungeon field underfoot or ahead, else the field actor in the direction
CAST2_08ea CAST2_08ea_SetLightTurns          # D_58a6: turns of light left
CAST2_08f8 CAST2_08f8_SetSpellStatus         # the status icon and its turns (P protection, Q quickness, C, N negate..), the effect and the party display
CAST2_0914 CAST2_0914_PlaceUrns              # puts the markers (potion tiles) for the party members who are gone into the Codex room; at positions of tables D_4b96..
CAST2_0e64 CAST2_0e64_Footstep               # a step of the walk in the shrine: a pause, the footstep, a pause
